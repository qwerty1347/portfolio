04 // highlights

기술적 의사결정

001

의존성 주입 + 모델 싱글톤

get_qdrant_client · get_embedding_model · get_yolo_model을 @lru_cache(maxsize=1)로 감싸 프로세스당 1회만 로드. FastAPI는 Depends로, Celery는 같은 캐시 함수를 직접 호출하여 완전히 동일한 객체를 재사용합니다. 라우터 import만으로 890MB 모델이 끌려오지 않습니다.

lru_cache DI singleton
002

lifespan 워밍업으로 콜드 스타트 제거

asynccontextmanager 기반 lifespan에서 부팅 시 Qdrant 클라이언트 · CLIP · YOLO를 미리 로드. 첫 요청에 추론 + 모델 로드가 동시에 발생해 응답이 느려지는 콜드 스타트를 차단합니다. 종료 시 Qdrant client를 명시적으로 close.

lifespan cold-start
003

이벤트 루프 보호 — to_thread

YOLO 추론, CLIP encode, Qdrant find_points 모두 동기·CPU/GPU bound 호출입니다. FruitSearchService.get_similarity_images 내부에서 모든 동기 호출을 asyncio.to_thread(...)로 워커 스레드에 위임해 FastAPI 이벤트 루프가 멈추는 사고를 차단했습니다.

asyncio GPU bound non-blocking
004

Celery 멱등 임베딩

embed_fruit_images 태스크는 파일 경로 기반의 uuid5(NAMESPACE_URL, path)를 PointID로 사용합니다. 같은 이미지가 재처리되어도 같은 ID로 upsert 되므로 중복 포인트가 생기지 않으며, acks_late + reject_on_worker_lost와 정합됩니다.

idempotent uuid5 upsert
005

레이어 분리 + 테스트 친화성

api / core / infrastructure / services / worker로 책임을 분리. 라우터는 얇게 유지하고, 서비스 계층이 도메인 로직을, infrastructure는 외부 자원 경계만 담당합니다. app.dependency_overrides로 Qdrant·CLIP·YOLO를 mock으로 바꿔 단위 테스트 가능.

layered testable overrides
006

입력 검증 — bbox 임계치

YOLO가 검출한 객체가 너무 작거나 비율이 비정상이면 임베딩 품질이 떨어집니다. min_size=10px · min_ratio=0.01 임계치로 사전 필터링하고, 미달 시 BusinessException으로 422를 반환해 노이즈가 벡터DB에 들어가지 않게 합니다.

validation bbox data quality

06 // pipeline

검색 파이프라인 — 핵심 코드

// app/services/fruit/search.py · 동기 호출은 모두 to_thread로 격리

search.py point.py common.py 
async def get_similarity_images(self, file: UploadFile) -> list[dict]:
    image = await save_temp_image(file)

    # 1. YOLO — 가장 신뢰도 높은 객체 1개 추출
    detection = await asyncio.to_thread(
        self.yolo.detect_top, image,
    )
    if not self._is_valid_bbox(detection.bbox):
        raise BusinessException(422, "object too small")

    # 2. CLIP — 크롭 영역 → 768d 벡터
    vector = await asyncio.to_thread(
        self.embed.encode, detection.cropped,
    )

    # 3. Qdrant — 코사인 유사도 Top-5
    points = await asyncio.to_thread(
        self.qdrant.find_points,
        collection="fruits", vector=vector, limit=5,
    )
    return [self._to_response(p) for p in points]
→ 의존성: FruitSearchService(qdrant, embed, yolo) ← Depends 주입 → 모든 추론 호출이 to_thread로 격리되어 동시 요청 처리 가능
