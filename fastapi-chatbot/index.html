LangChain ReAct 에이전트 챗봇_

FastAPI와 LangChain으로 만든 챗봇 API입니다.

  • 사용자 질문이 일상 대화인지 정보 요청인지 LLM으로 분류해서 응답 경로를 나눕니다.
  • 정보 요청이면 ReAct 에이전트가 벡터 DB 검색과 웹 검색 중 맞는 도구를 골라 호출합니다.
  • 단기 메모리 관리로 최근 대화 내용을 기억해 문맥에 맞게 답합니다.
  • 공지 데이터 임베딩은 Celery와 Redis로 백그라운드에서 처리합니다.
  • 전체 서비스는 Docker Compose로 띄울 수 있게 구성했습니다.

02 overview

동작 흐름

ReAct 에이전트 도구 선택 흐름

[AgentExecutor.ainvoke(input)]
       │
       │ REACT_PROMPT (hwchase17/react · 모듈 로드 시 1회 fetch)
       │ + tools description
       │   ├─ use_db_tool:  "내부 DB 검색에 사용."
       │   └─ use_web_tool: "내부 DB 외 검색에 사용."
       │
       ▼
[LLM 1차 추론]
       │
       │ Thought: 이 질문은 도매꾹과 관련이 ...
       │ Action: use_db_tool / use_web_tool
       │ Action Input: "..."
       │
       ▼
[Tool 실행 — 클로저로 주입된 DBSearch / WebSearch]
       │
       │ DBSearch.search_qdrant(query)
       │   → SentenceTransformer.encode (384-dim)
       │   → qdrant.find_points("board_notice", top_k=5)
       │
       │ WebSearch.search_serp(query)
       │   → SerpAPIWrapper(google, hl=ko, gl=kr)
       │   → knowledge_graph + organic_results 상위 3개 파싱
       │
       ▼
[intermediate_steps 에 (action, observation) 누적]
       │
       │ max_iterations=1 → 1회만 도구 호출
       │
       ▼
[result['intermediate_steps'] 의 observation 만 추출 → context]
