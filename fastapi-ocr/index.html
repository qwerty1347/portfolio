OCR API

이 프로젝트는 FastAPI를 기반으로 한 OCR 서비스로, 이미지나 스캔된 문서에서 텍스트를 추출하여 제공합니다.
Naver Clova OCR, EasyOCR, PaddleOCR 엔진을 활용하여 텍스트 추출이 가능하며, 다양한 이미지 형식을 지원합니다.

기술 스택

백엔드

  • Python 3.11
  • FastAPI
  • Pydantic

OCR 엔진

  • Naver CLOVA OCR
  • EasyOCR
  • PaddleOCR

DevOps

  • Docker
  • pytest

주요 기능

이미지 텍스트 추출

이미지에서 텍스트를 정확하게 인식하고 추출합니다. 다양한 이미지 형식(jpg, png, pdf 등)을 지원합니다.

다국어 지원

한국어, 영어, 일본어, 중국어 등 다양한 언어의 텍스트 인식을 지원합니다.

이미지 전처리

노이즈 제거, 명암 조정 등 이미지 품질 개선을 통한 정확도 향상

구현 상세

FastAPI 백엔드

비동기 처리가 가능한 FastAPI를 사용하여 고성능 RESTful API 서버를 구축했습니다. Swagger UI를 통한 API 문서화를 자동화하여 개발 생산성을 높였습니다.

Tesseract OCR 엔진

구글에서 개발한 Tesseract OCR 엔진을 사용하여 정확한 텍스트 인식을 구현했습니다. 다양한 언어와 폰트에 대한 학습된 모델을 활용하여 높은 정확도를 보장합니다.

이미지 전처리

OpenCV와 Pillow를 활용하여 이미지 품질을 개선하는 전처리 단계를 구현했습니다. 그레이스케일 변환, 이진화, 노이즈 제거 등을 통해 OCR 정확도를 크게 향상시켰습니다.

다국어 지원

한국어, 영어, 일본어, 중국어 등 다양한 언어를 지원합니다. 사용자가 선택한 언어에 따라 자동으로 적절한 OCR 모델을 로드하여 처리합니다.

향후 개선 계획

정확도 향상

딥러닝 기반 OCR 모델 적용

기존 Tesseract 엔진에 더해 딥러닝 기반의 최신 OCR 모델을 적용하여 낮은 품질의 이미지에서도 높은 정확도를 보장할 계획입니다.

딥러닝 정확도 향상
기능 확장

테이블 및 양식 인식

이미지 내의 표나 양식 구조를 인식하여 구조화된 데이터로 변환하는 기능을 추가할 예정입니다. 이를 통해 영수증, 명함, 신청서 등의 문서를 자동으로 처리할 수 있을 것입니다.

테이블 인식 양식 처리
사용자 경험

실시간 미리보기 및 편집

웹 인터페이스에서 실시간으로 텍스트 추출 결과를 확인하고 수정할 수 있는 기능을 추가할 계획입니다. 드래그 앤 드롭으로 이미지를 업로드하고 즉시 결과를 확인할 수 있는 직관적인 UI를 구현할 예정입니다.
