유사 이미지 검색 API

이 프로젝트는 FastAPI를 기반으로 사용자가 업로드한 이미지와 유사한 이미지를 벡터 데이터베이스 내에서 검색하여 제공하는 API 입니다.
YOLO 객체 검출 모델과 Qdrant 벡터 데이터베이스를 활용하여 정확하고 빠른 이미지 검색이 가능하며, 다양한 이미지 형식을 지원합니다.

주요 기능

이미지 텍스트 추출

이미지에서 텍스트를 정확하게 인식하고 추출합니다. 다양한 이미지 형식(jpg, png, pdf 등)을 지원합니다.

다국어 지원

한국어, 영어, 일본어, 중국어 등 다양한 언어의 텍스트 인식을 지원합니다.

이미지 전처리

노이즈 제거, 명암 조정 등 이미지 품질 개선을 통한 정확도 향상

스크린샷

이미지 검색 결과

프로젝트 상세

구현 상세

FastAPI 백엔드

비동기 처리가 가능한 FastAPI를 사용하여 고성능 RESTful API 서버를 구축했습니다. Swagger UI를 통한 API 문서화를 자동화하여 개발 생산성을 높였습니다.

YOLO 객체 검출

YOLO(You Only Look Once) 딥러닝 모델을 활용하여 이미지 내 객체를 정확하게 검출합니다. 실시간으로 객체의 위치와 종류를 식별하는 고성능 객체 인식 시스템을 구현했습니다.

Qdrant 벡터 검색

Qdrant 벡터 데이터베이스를 활용하여 대규모 이미지 데이터셋에서도 초고속 유사 이미지 검색이 가능합니다. 고차원 벡터 공간에서의 효율적인 유사도 검색을 구현했습니다.

이미지 임베딩

심층 신경망을 사용하여 이미지를 고차원 벡터 공간으로 변환하는 임베딩 시스템을 구축했습니다. 이를 통해 시각적 유사성에 기반한 정교한 이미지 검색이 가능합니다.
