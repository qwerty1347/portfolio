블로그 자동 포스팅_

FastAPI로 만든 블로그 자동 포스팅 API입니다.

  • Playwright로 네이버 금융·연예 랭킹 뉴스에서 기사 2건을 무작위로 골라 본문을 가져옵니다.
  • 가져온 기사는 LLM의 JSON 출력 모드를 써서 제목, 마크다운 본문, 태그로 나눈 블로그 글로 완성합니다.
  • 완성된 글은 Playwright로 티스토리에 자동으로 발행합니다.
  • OAuth 로그인 세션을 별도 저장하고 관리하여, 처음 한 번만 로그인하면 이후에는 자동으로 로그인됩니다.
