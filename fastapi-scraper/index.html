블로그 자동 포스팅_

금융·연예 랭킹 뉴스를 Playwright 로 스크래핑하고, LLM 으로 블로그용 콘텐츠로 가공한 뒤 티스토리에 자동 발행하는 큐레이션 파이프라인입니다. 카카오 OAuth 세션을 storage_state 로 보존해 재인증을 우회하고, 마크다운 모드로 에디터에 본문을 직접 주입하여 예약 발행까지 처리합니다.

02 overview

3단계 파이프라인 · scrape → summarize → publish

각 단계는 독립된 서비스 클래스로 분리되어 단위 디버깅·교체가 쉽고, 티스토리 발행 단계만 별도로 더 깊이 들여다보면 카카오 OAuth 우회 · CodeMirror 직접 주입 · 캘린더 UI 시뮬레이션이라는 세 가지 비표준 자동화 기법이 결합되어 있습니다.

전체 파이프라인 · scrape → summarize → publish

세 단계가 각각 FinanceNewsScrapService · NewsSummarizeService · TistoryPostService 로 분리되어 단위 실행·교체가 가능합니다. LLM 단계는 response_format="json_object" 강제 + 시스템 프롬프트의 형식 규칙 + 응답 후처리(제목 컷 / 줄바꿈 정리)로 발행 가능한 JSON 을 보장합니다.

storage_state 재사용으로 2FA·캡차가 포함된 카카오 OAuth 를 매번 통과하지 않아도 됩니다. CodeMirror 는 setValue 만으로는 Tistory 내부 상태가 갱신되지 않아 save() + refresh() + 이벤트 dispatch + 키보드 타이핑까지 결합해야 본문이 인식됩니다. 예약 발행도 textContent 변경이 아닌 실제 캘린더 셀 클릭으로 처리.

03 highlights

기술적 의사결정

001

카카오 OAuth 세션 재사용

첫 로그인만 사용자가 직접 진행한 후 Playwright context.storage_state(path=...) 로 쿠키·로컬스토리지를 파일에 보존. 이후 모든 실행은 create_context(storage_state=...) 로 카카오 OAuth 단계 전체를 우회합니다. 2FA·캡차 같은 자동화 어려운 단계도 한 번이면 끝.

OAuth storage_state session reuse
002

dialog 자동 분기 처리

티스토리 글쓰기 페이지는 다양한 confirm 다이얼로그를 띄웁니다 — "이어서 작성하시겠습니까?" (임시 글 복원), "작성 모드를 변경하시겠습니까?" (모드 전환) 등. page.on('dialog', ...) 에서 메시지 내용 보고 자동으로 dismiss() / accept() 분기 처리.

dialog auto-dispatch
003

예약 발행 캘린더 UI 클릭

button.btn_reserve 의 textContent 만 변경하면 표시만 바뀌고 Tistory 내부 상태는 갱신되지 않음. 캘린더 popup 을 열어 헤더(strong.txt_calendar)를 읽어 목표 달과 비교, btn_prev/btn_next 로 이동 후 table.tbl_calendar 내 날짜 셀을 실제로 클릭하는 방식으로 처리.

date picker UI simulation
004

LLM 응답 JSON 안정화

한글 본문에 등장하는 인용 따옴표, 줄바꿈, 외국어 문자 등은 LLM 이 JSON escape 를 깨먹기 쉬움. response_format 으로 형식 강제 + 시스템 프롬프트에 따옴표 사용 금지·줄바꿈 처리 규칙 명시 + 응답 후처리(제목 32자 컷, 줄바꿈 제거) 결합으로 발행 가능한 형태 보장.

JSON mode prompt engineering post-process
005

전역 logger + 카테고리 파일 로그

app/core/logger.py 의 단일 logger 객체 (formatter 가 호출 위치를 자동 캡처) + app/core/utils/log.py 의 save_log() 로 카테고리별 일자 파일 (storage/logs/tistory/YYYY-MM-DD.log) 분리. 디버그 실시간 로그와 영구 기록을 책임 분리.

logging file rotation
